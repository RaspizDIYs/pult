# CLAUDE.md

Подсказки для ИИ-агентов, которые работают в этом репозитории. `AGENTS.md` — симлинк на этот файл.

## Обзор

**Пульт** (`Pult`, `ru.raspizdiys.pult`) — локальное десктоп-приложение (macOS + Windows):
карта хостов, ВМ, контейнеров и сервисов RaspizDIYs с причиной отказа на карточке.
Проверки делает само приложение с машины пользователя, своего сервера нет.
Подробно — `docs/архитектура.md`.

Готов этап 0: каркас, сборка, релиз с автообновлением. Модули `src-tauri/src/{inventory,probes,engine,store,sources}` — пока пустые заглушки.

## Команды

```bash
npm install
npm run tauri dev                 # окно с горячей перезагрузкой
npm run build                     # tsc --noEmit + vite build (dist/ нужен и cargo)
cd src-tauri && cargo check && cargo test
```

Полную `tauri build` локально без нужды не гонять — тяжёлая, машина общая; релизные
сборки делает CI. Тяжёлые прогоны — через правила `agent-orch` (см. глобальный CLAUDE.md).

Проверка обновления без окна: `pult --check-update` / `pult --apply-update`
(вывод `ключ=значение`, код выхода 0 — успех).

## Релиз

- Версия — **только** в `package.json`; `tauri.conf.json` ссылается на него
  (`"version": "../package.json"`). Версию в `Cargo.toml` не трогать.
- `npm version X.Y.Z --no-git-tag-version` → коммит → `git tag -a vX.Y.Z -m "<что изменилось>"`
  → `git push origin main vX.Y.Z`. Аннотация тега = текст изменений в плашке обновления.
- `release.yml`: черновик → сборки мак (universal) + винда (NSIS) → задача `publish`
  сама собирает `latest.json` (три ключа: `darwin-aarch64`, `darwin-x86_64`,
  `windows-x86_64`) и публикует, только если собрались обе платформы.
  `uploadUpdaterJson` у `tauri-action` выключен намеренно: параллельные задачи
  перетирают `latest.json` друг друга.
- Ключ подписи — секреты `TAURI_SIGNING_PRIVATE_KEY(_PASSWORD)`. Без них сборка падает.
  Не менять `identifier` и `pubkey`: установленные копии перестанут обновляться.

## Архитектура

```
src/                 React: App.tsx, lib/updater.ts (хук проверки/установки), components/
src-tauri/src/lib.rs запуск, плагины (updater, process, log), флаги --check-update/--apply-update
src-tauri/src/       inventory/ probes/ engine/ store/ sources/ — по плану этапа 1
```

- Окно создаётся в `setup` (в конфиге `create: false`), чтобы в режиме флагов его не было.
- Лог — только в файл (`tauri-plugin-log`, LogDir): stdout занят выводом флагов.
- Ядро на Rust будет слать интерфейсу снимок и поток изменений через события Tauri;
  встроенного HTTP-сервера нет.

## Договорённости

- Репозиторий **публичный**: никаких реальных IP, имён хостов, ssh-алиасов, доменов
  инфраструктуры и токенов — ни в коде, ни в тестах, ни в коммитах. В примерах —
  `example.com`, `10.0.0.x`, `хост-а`. Реальный инвентарь — в приватном `RaspizDIYs/pult-inventory`.
- Идентификаторы в коде — по-английски; комментарии, документы, интерфейс,
  коммиты — по-русски. Комментарий объясняет «почему».
- Коммиты: `<type>(<scope>): описание`.
- Первая версия — только чтение: никаких действий над серверами.
- Компоненты UI — через `npx shadcn@latest add <имя>`, не писать вручную.
